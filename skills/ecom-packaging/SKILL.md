# 包装与开箱

展示产品包装的质感与开箱仪式感。

## 核心铁律

- 包装材质必须明确：`磨砂` `烫金` `浮雕` `丝带`
- 光线：**柔光箱** + **侧逆光** 凸显质感
- 色温 5000K，中性偏暖
- 产品占比 **35-40%**

## 3 种场景

### 1. 正面展示
包装盒正面居中，纯色背景 `#F5F1E8`，方正构图，展示品牌LOGO和设计。

### 2. 开箱瞬间
盒盖半开45°，内部产品若隐若现，周围散落丝带/填充纸。

### 3. 细节特写
微距拍logo烫金/浮雕纹理/封口贴纸，浅景深 f/2.8。
