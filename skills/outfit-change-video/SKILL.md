# 时尚角色换装视频·两步流

> AI 时尚角色档案 / 真人模特 Lookbook 展示：同一个女孩不同穿搭，高级棚拍，小红书时尚感，类似《VOGUE 数字模特换装》。

## 适用场景

- 现代装多套穿搭展示（Lookbook）
- 电商服饰换装演示
- 角色时尚档案 / 数字模特

## 核心设计原则（2026-08 定型）

1. **稳脸优先**：视频减少复杂动作，让模型稳定保持同一张脸——成功率远高于大幅动作版
2. **高级感锚定**：画面 = 高级时尚目录摄影（浅灰白棚、85mm、柔和光），不是动画/舞台
3. **换装机制**：完整人物剪影飞入重合，不是衣服覆盖/矩形切换
4. **两个变体**：主变体=Lookbook 换装；进阶变体=虚拟模特走出平面（更适合做账号标签）

## 流程总览

```
Step 1 生成人物参考图（生图平台 / doubao-seedream）
   └→ 得到 9:16 五人物穿搭拼贴图（中央主体 + 4 角小人物，白色虚线描边）
Step 2 上传参考图 → Seedance 2.0 图生视频
   └→ 生成 8s 9:16 卡点换装视频（白色光标点击 → 人物剪影飞入 → 换装）
```

## Step 2a：Seedance 视频提示词（现代 Lookbook 版 — 推荐）

> 上传 Step 1 参考图，替换服装描述后放入 Seedance 2.0 生成。**现代装版动作少、稳脸，成功率高于古风版。**

```
生成一段 8秒、9:16竖屏、高级时尚杂志风格换装视频。
参考上传图片中的女性角色。
必须保持同一个真人女性：
相同脸型
相同五官比例
相同眼睛特征
相同黑色长发
相同肤色
相同年龄感
相同身体比例
禁止重新生成不同人物。
【整体风格】
画面为高级时尚目录摄影。
浅灰白无缝影棚背景，柔和自然光，85mm 人像镜头。
整体感觉类似：
高级女装 Lookbook、
杂志大片、
真人模特展示。
中央人物最大，占画面60%以上。
四周固定悬浮四个小型人物穿搭展示。
每个人物外围有白色手绘虚线轮廓，如时尚贴纸。
不要出现 UI 界面。
【人物初始状态】
中央人物穿【初始造型，如：黑色针织上衣 + 白色短裤】。
镜头采用高机位近距离俯拍。
人物微微靠近镜头：
一只眼轻轻闭合
嘴角自然放松
眼神带一点俏皮、自信
头发自然散落，轻微随动作摆动。
【换装过程】
0-2秒
中央人物保持【初始造型】。
她慢慢抬头看向镜头。
左上角穿搭人物出现轻微发光效果。
一个白色手势光标轻触左上人物。
左上人物变成完整人物剪影，
沿斜方向移动到中央。

完成第一次换装：
【初始造型】→【造型1，如：白色简约针织套装】。
2-4秒
人物保持同一个脸。
轻轻转身45度。
衣服产生真实布料褶皱。
右上人物被点击。
完整人物贴纸飞入中央。
完成第二次换装：
【造型1】→【造型2，如：浅蓝衬衫造型】。
4-6秒
人物回到正面。
手轻轻整理头发。
左侧人物飞入。
完成第三次换装：
【造型2】→【造型3，如：灰色针织背心 + 白色裤装】。
6-8秒
最后一次换装。
左下人物飞入中央。
完成第四套造型：
【造型3】→【造型4，如：白色背心 + 牛仔裤】。
最后：
人物靠近镜头。
轻微歪头。
保持原图中的温柔、俏皮眼神。
停留结束。
【动作要求】
动作不要夸张。
保持：
真人模特自然动作
轻微呼吸
头发自然摆动
衣服真实布料变化
不要：
快速舞蹈
夸张转圈
大幅肢体动作
【换装限制】
必须：
完整人物剪影飞入换装。
不是：
衣服覆盖
身体融合
矩形图片切换
换装前后：

六个人物
脸变化
手指错误
```

## Step 2b：进阶变体 — 虚拟模特走出平面（账号标签方向）

> 定位「下一代 Designer」的更强方向：AI 生成的虚拟模特从平面海报里"走出来"。适合做账号记忆点，比普通换装视频更容易形成标签。骨架 = Step 1 的拼贴参考图，但中央主体动作是"出屏"。

```
生成一段 8秒、9:16竖屏、超现实时尚大片视频。
参考上传图片中的女性角色。
必须保持同一个真人女性：相同脸型、五官比例、眼睛特征、发型、肤色、年龄感、身体比例。
【开场】
画面是一张竖版时尚海报贴在半透明玻璃平面上。
海报里是【中央造型】的女模全身像，四周有白色手绘虚线轮廓。
镜头缓慢推近海报。
【出屏时刻】
女模在海报内开始轻微活动：眨眼、头发飘动。
随后她的手臂先探出海报边缘，像从纸面里伸出来。
接着她整个人跨出海报，从平面变成立体真人，站到海报前方。
身上【造型1，如：黑色针织+白色短裤】完整可见。
她回头看向身后海报里的自己，再转回镜头。
【走动与定格】
女模向前走两步，停在画面中央偏右。
轻微歪头，眼神俏皮自信，嘴角放松。
海报在她身后保持完整，四个虚线小人物仍在海报里。
最后画面定格在：真人女模在前，海报平面在后，形成虚实对比。
【动作要求】
动作幅度小、节奏慢，突出"从平面到立体"的质感转变。
头发、衣摆自然摆动。
【换装/光影】
可让女模抬手一挥，海报中四个虚线小人物依次亮起；
或保持单一造型，仅做"走出海报"一个核心动作（推荐先做单造型，成功率更高）。
【禁止】
不要出现动画/漫画/游戏渲染质感
不要脸变化、多余人物、手指错误、AI塑料皮肤
不要 UI 界面、文字、水印
```

### 视频校验清单（生成后检查，两个变体通用）

- [ ] 8s / 9:16 竖屏
- [ ] 换装前后面完全一致（同一张脸）
- [ ] 4 个小人物全程保留在原位（点击后不消失）
- [ ] 换装 = 完整人物剪影飞入重合（非衣服覆盖/矩形切换）
- [ ] 无残影、无双重人物、无服装叠穿
- [ ] 动作自然克制，无夸张舞蹈/转圈
- [ ] 无 UI、无文字、无水印
- [ ] （出屏变体）人物从平面到立体的过渡自然，虚实对比成立

## 变体选择指南

| 目标 | 选哪个 |
|------|--------|
| 常规穿搭展示 / 电商换装 | **Step 2a 现代 Lookbook**（稳脸，成功率最高） |
| 做账号标签 / "下一代 Designer"定位 | **Step 2b 虚拟模特出屏**（先做单造型，成功率更高） |
| 古风/特定主题 | 替换服装描述为对应风格，结构不变 |
