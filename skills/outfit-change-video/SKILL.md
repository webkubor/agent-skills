# 穿搭换装视频·两步流

> 第一步出人物参考图（5 套穿搭拼贴）→ 第二步用参考图生成 Seedance 卡点换装视频。

## 适用场景

- 古风/现代角色 5 套穿搭展示
- 电商服饰换装演示
- 角色设定可视化（同一人物多造型）

## 流程总览

```
Step 1 生成人物参考图（生图平台 / doubao-seedream）
   └→ 得到 9:16 五人物穿搭拼贴图（中央主体 + 4 角小人物，白色虚线描边）
Step 2 上传参考图 → Seedance 2.0 图生视频
   └→ 生成 8s 9:16 卡点换装视频（鼠标点击 → 人物贴图飞入 → 换装）
```

## Step 2：Seedance 2.0 视频 Prompt

> 上传 Step 1 的参考图，替换【】占位符后放入 Seedance 2.0 生成（8s / 9:16 / 高机位俯拍）。

```
参考上传图片中的女主形象、古风发型头饰、耳饰、5套汉服造型和整体画面布局，生成一段 8秒、9:16竖屏 的高机位卡点换装视频。
【人物与画面】
中央女主保持上传图片中的脸型、五官、肤色、黑色古风长发、半盘发造型、银色发饰、珍珠垂坠耳饰和整体清冷温婉气质一致。 初始造型使用中央穿搭：白色外披大袖袍 + 蓝色绣纹交领内层 + 浅蓝色长裙，腰间有银色腰饰与流苏。
画面四周固定悬浮4个小型穿搭人物，保持图片中的位置、比例、服装和朝向：
左上：白色上衣 + 浅蓝色百褶长裙 + 蓝色腰带
右上：白色内搭 + 蓝色无袖马甲式长裙，带银色绣纹装饰
左侧中部：浅蓝色内裙 + 深蓝色交领层次 + 白色外披长袖袍
左下：浅灰紫色外披 + 米白色内搭 + 深蓝色绣纹下裙
四个小人物都是完整人物抠像，沿真实身体轮廓裁切，外沿有清楚的白色虚线描边，像悬浮人物贴纸，不是矩形缩略图。
【场景与机位】
浅灰白色无影棚，背景与地面自然连成一体，光线柔和通透，具有干净细腻的古风人物棚拍质感。 摄影机固定在女主前上方，采用近距离高机位俯拍，约向下 30–35度。女主自然抬眼看向镜头，头部和上半身更靠近镜头，裙摆向画面下方展开。 全程固定机位，不推拉、不摇镜、不旋转、不变焦。
【换装机制】
画面中出现一个白色手形鼠标指针，依次点击四个描边人物。 每次点击后，原位置人物继续保留，同时复制出一个相同的完整人物抠像，从原位置沿斜向快速飞向中央并迅速放大。 放大过程中，白色虚线描边始终贴合完整人物轮廓。 当飞来的描边人物与中央女主的头部、肩膀、腰部和动作姿势完全重合时，中央女主切换成对应穿搭，并连续完成原来的动作。 飞向中央的是完整人物贴图，不是单独衣服，也不是矩形卡片。
【时间线】
0.00–1.25秒
女主穿初始白蓝色大袖袍造型，从画面下方偏右轻缓靠近镜头，身体微微前倾，宽大袖摆和裙摆自然轻摆，抬眼看向高处镜头，气质温柔安静。 鼠标点击左上人物。左上人物从左上斜向右下飞向中央并放大。 约 1.25秒 完成第一次换装，切换成白衣浅蓝长裙造型，继续原来的靠近动作。
1.25–2.95秒
女主一只手自然落在腰前，另一只手轻提袖口，身体轻微摆动并带淡淡微笑。随后向左缓慢转身，逐渐露出侧面和半背面，长发与发饰随转身轻轻摆动。 鼠标点击右上人物。该人物从右上斜向左下飞向中央并放大。 约 2.95秒 完成第二次换装，切换成白色内搭 + 蓝色无袖马甲式长裙，并继续同一个旋转方向。
2.95–4.40秒
女主转回正面，衣摆和发丝自然回落，动作轻盈流畅。转正后身体短促下沉，双臂轻微向两侧展开，让袖摆自然打开。 鼠标点击左侧中部人物。该人物从左侧飞向中央并放大。 约 4.40秒 完成第三次换装，切换成浅蓝内裙 + 深蓝交领 + 白色外披长袖袍。
4.40–6.55秒
女主双手收于身前，低头轻摆肩膀，随后连续左右自然歪头，再抬眼看向镜头，然后将视线转向左下人物，情绪温柔含蓄。 鼠标点击左下人物。该人物从左下斜向右上飞向中央并放大。 约 6.55秒 完成第四次换装，切换成浅灰紫外披 + 米白内搭 + 深蓝绣纹下裙。
6.55–8.00秒
女主一只手轻扶衣襟，另一只手自然垂落，头部先看向侧面。 随后身体转回正面，自然歪头，抬眼直视高处镜头，以优雅、清冷、古风感强的姿势结束。衣摆和长袖在结尾保持轻微自然垂落感。
【声音】
无背景音乐。 保留：
鼠标点击声
人物贴图飞入时的短促移动音效
每次换装完成时清晰利落的卡点音效
轻微衣料摩擦感音效可适度加入
【强制约束】
四个描边人物全程固定在原位置，点击后原人物不消失
四次换装分别在约 1.25秒、2.95秒、4.40秒、6.55秒 完成
换装前后保持同一张脸、同一发型、同一头饰耳饰、同一身材比例
动作方向、重心和手臂位置连续
换装必须由完整人物抠像飞入、放大、重合完成
不要生成矩形缩略图、人物残影、双重人物、服装叠穿、错误肢体或镜头运动
汉服长袖、披帛、裙摆和流苏必须有自然垂坠和轻微惯性，不能僵硬漂浮
```

### 视频校验清单（生成后检查）

- [ ] 8s / 9:16 竖屏
- [ ] 4 次换装分别在 ~1.25 / 2.95 / 4.40 / 6.55s 完成
- [ ] 换装前后同一张脸、同一发型头饰
- [ ] 4 个小人物全程保留在原位（点击后不消失）
- [ ] 无残影、无双重人物、无服装叠穿
- [ ] 固定机位，无推拉摇移
- [ ] 无 BGM，保留点击/飞入/卡点音效
