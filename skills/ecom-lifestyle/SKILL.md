# 电商场景生活图

把产品放进**真实使用场景**，让消费者"看到自己在用"。

## 核心铁律

- 产品占比 **20-25%**（这是场景图，不是产品图）
- 留白 **50%+**
- 色温 **5500K** 自然日光
- 所有颜色用 hex：白底 `#FFFFFF`，背景 `#F5F1E8`
- 结尾加否定清单：`不要添加：水印、假logo、额外文字、装饰元素`

## Prompt 结构

```
1. Campaign Style Lock（多图时每张一致）
2. 场景描述 + 产品融入方式
3. 光线方向和质量（侧逆光/柔光窗光）
4. 构图 85mm f/1.8 浅景深
5. 负面约束
```

## 场景模板

**窗边晨光**：自然柔光从左侧窗射入，产品在窗边桌上，背景虚化成生活空间。色温 5000K。

**户外下午茶**：庭院/露台自然光，产品在木桌上，绿植虚化背景。色温 5500K。

**居家夜读**：暖黄台灯光从右侧打在产品上，深色背景。色温 3200K。
